# 双苇扣 · Twin Reed

鞋面前部的古铜穿带饰扣。正面朝向观察者时，左叶较短且有通孔，右叶较长；两叶根部相连。背桥有两个固定脚，让细带从中穿过，或用线把桥缝在鞋面。当前为数字影视道具，尺寸用于在场景中保持比例。

- 模型外包尺寸约为 31.24 × 50.02 × 8.89 mm（宽、高、总厚），短叶孔直径 4 mm，背桥中部净空约 4.1 mm。
- GLB 以米为单位，+Y 指向叶尖，+Z 指向装饰正面；X 方向从短叶指向长叶。原点位于共根底部附近。各部件具名，可在支持 glTF 2.0 的工具中单独选取或换材质。
- 正、右、俯三图按同一比例正交投影；右侧附背部斜视图。环境四图使用相同模型。透明正面与斜视 PNG 可以直接作为合成素材。
