# 把双苇扣装进一个镜头

**先选佩戴位置。** 找一个角色本来就需要连接两件东西的部位。例片用鞋面带；盔甲可用披风系结，软帽可用帽带。先在原服装上指出扣件的背桥和接触阴影会落在哪里，再决定正面朝向。

| 手头的素材 | 做法 | 回看时检查 |
| --- | --- | --- |
| 能控制骨骼的角色或三维场景 | 导入 GLB，把背部桥贴合衣料，用父子关系绑定鞋或服装骨骼；让前后景共用场景灯光 | 抬脚旋转时能看到侧面厚度，扣不会滑到另一只脚 |
| 已有动画或实拍 | 将透明斜视图叠加到跟踪点，用位置、旋转、缩放和遮罩处理；大的侧转改用模型重新渲染 | 前景经过时遮住扣；退出画面后从原位置重现 |
| 允许首帧或多图参考的视频生成器 | 先做已经佩戴的首帧，工具支持时再附三视图。每次只试一个动作，保存原始输出和模型版本 | 是否变成两只扣、交换长短叶、丢失短叶孔或漂移 |

**可复制的镜头描述**

> 侧面近景。人物抬起穿着水晶鞋的脚，向前踏下一层石阶。古铜双苇扣固定在鞋面带上，两枚不等长的叶片从同一根部伸出，短叶有小圆孔。鞋尖朝下时，扣跟着脚背转动；裙边盖住它片刻，裙边扬起后露出同一件扣。暖灯沿金属边缘扫过。

**推荐的验收办法。** 同一镜头留一份带扣和一份无扣的输出。正常速度先看动作是否自然；逐帧再对照形状、位置与遮挡。远景很难看见小孔是合理的，给一次合乎剧情的近景即可。可以让第一次看的人判断道具有没有破坏故事气氛，再让看过项目说明的人从三件服饰中指出哪一件带有印记。两次观察回答不同的问题。

**声明可以随作品走。** 建议在发布页或片尾写明作品名、同人及 AI 辅助情况、用途、印记项目链接。若取得了授权，可另列授权方、范围或公开指南。单看一个物件仍然无法判断谁拥有角色权利，也无法防止别人移除或冒用标记。
