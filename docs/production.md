# 《十二点以后》制作记录

成片 10 秒，960 × 540，24 fps，H.264 视频与 AAC 单声道音效。题材取自《灰姑娘》午夜失鞋的传统情节。角色服装、场景、取景和动作在本项目中重新制作。例片及仓库没有取用参考动画的原帧、配乐、对白或音轨。

| 成片时间 | 画面和动作 | 扣的处理 |
| --- | --- | --- |
| 0–1.35 秒 | 午夜钟面，钟声先入 | 道具在镜头外 |
| 1.35–4.65 秒 | 侧向跟拍，下阶奔跑，上身为剪纸偶，腿和脚分别运动 | 靠摄影机一侧的鞋上有一枚扣，与鞋同步旋转 |
| 4.65–7.15 秒 | 切到低机位跟脚，约 5.4 秒鞋离脚，约 6.1 秒落在石阶上 | 离脚后扣与鞋共用落下、触地和轻微回弹的轨迹 |
| 7.15–10 秒 | 留在鞋上的特写，缓慢靠近 | 保留金属轮廓，可用无扣对照帧核验差别 |

## 从素材重建

在仓库根目录执行下列命令。需要 Python 3.13 和带 libx264、AAC 编码器的 ffmpeg。本项目把使用的画稿一并放在仓库里，重建无需调用图像生成服务。

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python design/build.py
python tools/render_film.py
```

第一个脚本导出米制 GLB、三视图、斜视图和光照参考。第二个脚本把斜视图固定在水晶鞋的鞋面，将双腿、裙身和鞋分层合成；声轨在渲染时由频率、包络和事件时间合成。带扣和无扣的 PNG 均导出成片第 8 秒的机位。程序合成复现的是这段剪纸偶表演。如何跟踪或驱动用户自己的角色见[接入制作流程](usage.md)。

## 美术与来源

| 资产 | 制作方式 |
| --- | --- |
| 宫殿布景 palace.png | 内置 imagegen。侧立面的中古宫殿、左侧午夜钟楼、右侧远镇剪影；蓝黑纸本、赭金灯光，无人物。 |
| 角色层 runner.png | 内置 imagegen。向右奔跑、回头听钟声的女主角；紫红紧身上衣、奶油色袖、红裙与绿腰带。上身与裙摆为透明剪纸偶，腿脚另行驱动。 |
| 水晶鞋 slipper.png | 内置 imagegen。右向侧视、低跟、淡青玻璃与细金纹，鞋背预留扣件位置。带扣和无扣镜头共用此底图。 |
| 材质概念图 material-study.jpg | 内置 imagegen 以本项目的三视图为设计参考，表现旧铜、棕色皮带与酒红羊毛。图中短叶孔穿带属于陈设变化，背桥装配以 GLB 为准。该图为概念渲染。 |
| 双苇扣 | 自建参数化轮廓、叶脉、短叶通孔和背桥，导出 GLB 并离线投影。日光、火光、水下和熏黑版本均使用同一套几何，仅调整方向光与色调，属于美术参考。 |
| 音效 | 代码合成钟声、脚步和玻璃轻响，见 render_film.py。 |
